# 手环全能计算器 · 源码审查仓库

小米手环 Vela 快应用《手环全能计算器》，当前版本 **1.5.8（versionCode 47）**，designWidth 336，面向小米手环 8 Pro / 9 Pro / 10 Pro。本仓库供外部独立审查使用，目录结构与真实工程保持一致。

## 文件说明

| 文件 | 内容 |
| --- | --- |
| `src/common/calc.js` | 计算引擎：表达式求值、分数/根式精确形、解方程（一次/二次/方程组）、函数图象数据、单位换算 |
| `src/pages/index/index.ux` | 全部页面与交互逻辑（Vela 快应用单页源码，含显示层格式化与布局） |

| 安装包 | 编译后的 `.rpk`（即发售成品，与上述源码对应）：[下载 calc-1.5.8.rpk](https://muse.ai/files/1321696044366246/1483187287250886/cl1rfhn27l7bdh63g1ah7epm/___1.5.8.rpk)（链接有效期至 2026-11-16，过期请联系作者刷新） |

## 1.5.8 相对 1.5.7 的变化（回应上一轮独立审计的 15 项清单）

经作者方逐项实跑复核（`tests/regression-1.5.8.mjs` 锁定）：

**属实并已修复：**

1. **判别容差过粗**：相对容差 1e-12 时，`{x+y=2; x+(1+1e-13)y=2+1e-13}`（真唯一解）误判无穷多解、`x²+2x+(1−1e-13)`（真两根）误判重根。浮点噪声实际只有 1e-16 级，`solveQuad()` 与 `solveSystem()` 的容差同步收紧到 1e-14，全部旧噪声守卫实测不回退。
2. **`solveSystem()` 缺有限性守卫**：NaN/Infinity 输入旧版一律落「无解」分支。已加入口与结果守卫，统一返回「数字太大，超出精确计算范围」；`solveLinear()` 顺带补中间量守卫（防 Inf−Inf=NaN 被当解）。
3. **`fracCalc()` 中间乘积提前溢出**：乘除改交叉约分、加减先约分母 gcd，如 `1000000000/1000000001 × 1000000001/1000000000 = 1` 不再误报；真溢出仍报错。
4. **根式自检容差对极小根偏宽**：`quadRadStrs()`/`quadImRad()` 的数值自检由 `1e-9·max(1,|v|)` 改为 `1e-9·|v|+1e-12`。

**经复核不属实（证据已写入回归测试）：** tan() 奇点（90°/270°/450°/−90° 均已报「没有意义」）；隐含乘法（输入层已补 ×，`2sin(30)=1`、`2√(9)=6` 页面实测通过）；`evaluate()` 返回 Infinity（「=」键对「溢出」结果明确拦截，不记历史、不污染 Ans）；绘图渐近线连线（绘图为 90 点点绘、无连线段，|y|>1e6 跳点）；历史存储损坏（已有 try/catch＋JSON 容错＋条目过滤）；`gcdLcm()` 安全整数（早已有守卫）。

**已定版取舍（未改）：** 原尺度判别式非有限仍先报错（如 `(1e200,1e200,1e200)`，b² 已溢出成 NaN）；`toFraction()` 的 1e-10 容差为全应用统一口径；数据单位 KB/MB 按 1024（与国内信息技术教材口径一致）。

（1.5.7 的变化——二次方程判别式尺度误判、方程组下溢、`solveLinear()` 守卫——见 git 历史与 `tests/regression-1.5.7.mjs`。）

## 测试如何运行

本地全套共 **1384 条断言全过**（作者工程内运行，含 paykey 相关部分）。

本仓库可**直接独立运行**的（851 条）：

```bash
node tests/audit-scenarios.mjs      # 84 条
node tests/regression-1.4.17.mjs    # 60 条
node tests/regression-1.5.0.mjs     # 81 条
node tests/regression-1.5.2.mjs     # 112 条
node tests/regression-1.5.5.mjs     # 514 条
```

**依赖未公开模块、公开仓无法独立运行**的（文件内容与作者本地版逐字一致，未做删改）：

- `tests/run-tests.js`、`tests/regression-1.5.4.mjs`、`tests/regression-1.5.6.mjs`、`tests/regression-1.5.7.mjs`、`tests/regression-1.5.8.mjs`：页面测试 harness 需要 `src/common/paykey.js`（未公开）注入；`run-tests.js` 另含收费系统算法断言，以及对作者本地另一项目（乒乓手环应用）密钥模块的交叉隔离校验（含本机绝对路径）。这些断言只能在作者本地复现，公开仓中运行会在读取 paykey.js 处报 ENOENT——这是预期行为，不是测试失败。

## 审查约定

- 结论请区分「确定存在的问题 / 潜在风险 / 已验证正常」，并给出可复现的输入。
- 以下为产品定版行为、不是 Bug：结果能写成精确分数时同屏双显（小数+分数同行，连接号按回读全等取 = 或 ≈）；不采用卡西欧「分数与小数混算结果恒为小数」规则，分数钮是否出现只看结果值；无理根给根式精确形、恢复不了自动回退小数；单位换算「带回计算」带回的是换算过程式（如 `5×2.54`）而非裸结果。
