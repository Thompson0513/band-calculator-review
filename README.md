## 本版（1.5.6）针对上一轮审查报告的修复，请重点复验

1. **方程组小系数误判**：`solveSystem` 的行列式容差已去掉 `max(1, …)` 下限，改为纯相对尺度。复验：`{0.0000001x=0.0000001; 0.0000001y=0.0000001}` 应为唯一解 x=1, y=1；同时 `{0.1x+0.7y=1; 0.3x+2.1y=3}` 必须仍判无穷多解（不许回退）。
2. **极小数归零**：`cleanNum` 改为「12 位有效数字 round-trip 精确」才放行极小值。复验：`1÷10^16` 应显示 `1e-16` 而非 0；但 `sin(180°)`、`0.1+0.2−0.3` 的浮点噪声仍应归零。
3. **二次方程溢出**：系数 1e200 / 1e308 时应报「数字太大，超出精确计算范围」，不许返回 Infinity / NaN 根或编造重根；系数 1e154 的合法大根应正常给出。

## 以下为开发者有意定版的产品行为，不要当 Bug 报（可复核实现是否自洽）

- 结果有精确分数时，小数与分数同屏给出（主界面靠小钮切换直显），判准只看结果值；表达式带小数点也照样给分数（不用卡西欧的混算规则，这是产品决定）。
- 单位换算结果只显示小数，但「带回计算」带回的是换算过程式（如 `5×2.54`），不是裸数字。
- 无理根给根式精确形（如 `(3+√17)/4`），系数无法精确恢复时回退小数；图象页两个根式并排超行宽时回退小数行。
- 单位换算结果不加分数标注。
